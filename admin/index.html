Connect a phone

Open these settings on your phone — handy for typing longer text. The phone must be on the same WiFi as the board (or joined to the board's hotspot below).

WiFi hotspot

Turn the board into its own WiFi access point. Then connect your phone to it and open these settings — useful where the board has no other WiFi. (Board device only.)

Checking…

Join a WiFi network

Connect the board to an existing WiFi network. (Board device only.) The board has one WiFi radio, so joining a network turns the hotspot off.

Displays

Choose which screen shows the board. Works on the board device itself (not from a phone/dev browser). You can also press Super+P on the device to toggle.

Software update

Fetch the latest Salah Board code from GitHub and apply it. The board must be connected to the internet. (Board device only.)

Preview & test

Force the board into any state without waiting for that time of day — great for checking the theme and content. Save your settings first so the preview reflects them.

Normal screen — fine-tune

Every TV shows the board a little differently. Adjust each element's size here (100% = the theme's normal size), or hide the ones you don't need. The preview below updates as you go; press Save to send it to the board — check the real screen, since that is what the congregation sees.
