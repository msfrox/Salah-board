# Knowledge base

Durable research notes, decisions, and findings for Salah Board that don't
belong in the formal specs (`SPEC.md`, `ARCHITECTURE.md`, etc.) but are
worth keeping so we don't re-research them.

Managed by the `kb` skill (`.claude/skills/kb/`). Ask Claude to
"save this to the kb" or "check the kb for …".

## How it works

- One Markdown file per entry: `YYYY-MM-<slug>.md`.
- Each entry starts with a metadata block (date, tags, status, related)
  then Question / Conclusion / Reasoning / Sources.
- This index lists every entry, newest first.
